# 『팀이 쓰는 자동화』 예제 저장소

n8n으로 Slack · Jira · GitHub · AI를 잇는 실무 워크플로 — 책의 실습 자료 저장소입니다.

> **집필 중입니다.** 내용은 예고 없이 바뀔 수 있습니다.

## 구성

| 경로 | 내용 |
|---|---|
| `workflows/` | 워크플로 JSON (n8n에서 import) |
| `seeds/` | Jira · Slack · GitHub 실습용 시드 데이터 생성 스크립트 |
| `docs/` | 정오표 · 보충 페이지 · 서비스 화면 변경 대응 |

## 브랜치

장별 완성 상태를 브랜치로 나눕니다. 실습 중 막히면 해당 장의 브랜치와 비교하세요.

## 주의

- 워크플로 JSON에는 **credential 값이 들어 있지 않습니다.** import 후 각자 계정으로 다시 연결해야 합니다.
- 실습은 **개인 샌드박스 계정**에서 하세요. 회사 워크스페이스에 붙이지 마세요.
